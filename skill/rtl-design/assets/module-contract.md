# RTL 模块设计与评审模板

复制后填写实际约定；未填项不作为验收结果。

| 项目 | 需确定的内容 |
| --- | --- |
| 职责/非职责 | 本模块具体算子、状态，交由上下游处理什么 |
| 时钟/复位 | 域、频率目标、极性、同步释放、复位后的valid和地址 |
| 输入事务 | data/weight/bias/模式何时采样，是否有ready，暂停时谁保持 |
| 定点格式 | 每个端口signed、位宽、二进制小数位、舍入和溢出 |
| 存储接口 | 读请求到数据延迟、地址单位、read-during-write约定 |
| 流水线 | 每一级数据、valid和侧带；外部cycle到输出cycle差 |
| 状态优先级 | reset / clear / 模式切换 / 有效输入 / 空拍 |
| 输出语义 | spike或acc、last标签、输出与清零的关系 |
| 最坏范围 | lane和、kernel/通道/时间步累加及bias上界 |
| 测试与证据 | 已知数值、负数、阈值、边界、空拍、clear、阻塞；对应日志 |
| 实现验收 | LUT/BRAM/URAM/DSP、setup/hold、约束覆盖、CDC |

修改时写出“原周期行为→新周期行为→受影响模块→新增区分用例”，避免把大段重写当作验证。
