## 二、RTL仿真契约与覆盖

模板为32通道、16位权重、32位累加、8路分组的简化PE。TB采用独立顺序点积/状态模型，逐拍检查输出valid、数据和last。确定性场景覆盖阈值相等、负和、权重有符号极值、空拍、连续输入、clear丢弃在途事务和last+fire；固定seed混合输入再扩展覆盖。

本次接受193个输入事务，检查74个有效输出事件，运行255个时钟观察周期。未给fire/last的输入仅更新内部状态，因此输出数不应等于输入数。clear还会丢弃在途事务。仿真通过不能推导全网络精度、池化/反卷积/旁路、输出背压、CDC或时序收敛。

可重跑：在独立构建目录，用绝对源码路径代入以下命令，避免生成物进入设计目录：

```powershell
xvlog --sv <绝对路径>/skill/rtl-design/assets/spike_mac.sv <绝对路径>/skill/rtl-design/assets/tb_spike_mac.sv
xelab tb_spike_mac -s skill_mac_test
xsim skill_mac_test -runall
```

尖括号部分是说明性占位，执行时替换为真实路径；路径有空格时加引号。仓库内本次构建目录为 `.sim-build/`，已局部忽略，不交付仿真缓存。`rtl-simulation.json` 保存源码SHA-256、命令、工具版本和通过标记。
